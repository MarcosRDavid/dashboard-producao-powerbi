# 📊 Dashboard de Produção - Power BI

Este projeto apresenta um dashboard de produção desenvolvido no Power BI utilizando Excel como fonte de dados.

## Indicadores analisados

- Total aprovado
- Total rejeitado
- Horas produzidas
- Horas paradas
- Produção mensal
- Disponibilidade
- Índice de qualidade
